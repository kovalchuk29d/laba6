## 2. Контрольне запитання

**Запитання:** `Як можна імпортувати всі функції з модуля, не використовуючи оператор `*`?`

**Відповідь:**

`Щоб уникнути засмічення простору імен, можна скористатися явним імпортом, перерахувавши всі необхідні функції через кому після ключового
слова import (наприклад, from module import func1, func2). Інший спосіб — імпортувати сам об'єкт модуля цілком за допомогою конструкції 
import module і в подальшому звертатися до його функцій через крапку (module.func1()). Для зручності та скорочення коду такому модулю можна 
призначити короткий псевдонім`
